# Clay: sample UI (browser-only demo)

The original Clay procurement UI. It needs **no backend**: all data lives in
`src/data.js` (REQ-1001 from the brief, REQ-1002 to REQ-1008 invented samples).
Use it to demo the PM, HOD and Admin screens. The connected UI is in `../Frontend`.

```sh
npm install
npm run dev      # http://localhost:5175
```

Log in as Debashis or Anirban (PM), Vikram (HOD) or Admin. Actions work in memory and reset on reload.
